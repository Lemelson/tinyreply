Built for reliability

One small program for one creator — not a 10-container agency platform

Most open-source ManyChat clones need Postgres, Redis, Node, SMTP, and a public webhook URL just to send a DM. tinyreply strips all of that away and focuses on delivery guarantees.

Guarantee

Never double-sends

Each DM is claimed in SQLite before the HTTP request leaves. Crashes, restarts, or ambiguous Meta timeouts are marked uncertain and never blindly retried.

Matching

Understands real comments

guide, GUIDE!!, guiiide 🔥, @friend guide, and Latin/Cyrillic look-alikes all match. Verified on 1,108 real comments from a live reel.

Backlog

Serves the full 7-day window

If your server was offline or a reel goes viral past the hourly rate limit, the queue drains oldest-first across Meta's full 7-day private reply window.

Zero ports

No webhooks or domain required

The core bot polls Meta over outbound HTTPS only. Run it behind NAT or on a $3 VPS alongside other tools with zero open ports and zero TLS certs to renew.

Optional funnel

Buttons, follow checks & A/B tests

Add the optional stdlib web.py process when you want "Get it" buttons, follow gates, bot-filtered click tracking, A/B variants, and the web panel.

Safety

Armed manually, alerted in Telegram

Fresh installs and config changes start with send budget 0. Nothing sends until you arm it, disarm stops immediately, and Telegram alerts repeat if anyone gets stuck.

Quick Start

Running in 5 minutes on any Linux box or Mac

Zero pip install, zero containers, zero build tools. Just Python 3.12+ and an Instagram Professional account connected to your Meta developer app.

  1. 1Clone the repo and drop your IG_ACCESS_TOKEN into state/.env.
  2. 2List recent reels with bot.py media and add keyword + DM text to config.json.
  3. 3Verify with check --online and dry-run once before arming your send budget.
Full Setup Guide Download Release
bash — quick start 
git clone https://github.com/Lemelson/tinyreply.git
cd tinyreply/autoreply
mkdir -p state && chmod 700 state
cp ../.env.example state/.env && chmod 600 state/.env
cp config.example.json state/config.json

# Verify token, list reels, dry-run without sending
python3 bot.py check --online
python3 bot.py media
python3 bot.py once
python3 bot.py report

# When the report looks right, arm and run
python3 bot.py arm 20
python3 bot.py run
